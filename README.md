## 日本語

### 📖 概要

手描きの文字やイラストの画像を読み込み、描かれた部分をそのまま当たり判定のある足場に変換する 2D プラットフォーマーです。
ゲームエンジンは使用せず、C++ と DirectX 11 で描画・入力・当たり判定・ステージ管理を実装しています。

### ✨ 主な機能

- **画像 → 足場の自動変換**（`ImageToPlatform.h`）
  - 画像を一定サイズのグリッドに分割し、アルファ値と明るさから「インク」ピクセルを判定
  - インクの割合がしきい値を超えたセルを矩形の足場（AABB）として生成
  - DirectX に依存しない純粋なロジックとして分離し、単体テスト（`test_image_to_platform.cpp`）で検証
- **ゲーム内レベルエディタ**（`PlatformEditor`）
  - デバッグ飛行モード中、マウスで足場・画像グループ・チェックポイントを選択、移動、リサイズ
  - 画像足場は「見た目のスプライト＋生成された当たり判定ブロック群」を 1 つのグループとして一括操作
  - `S` キーで編集結果をテキストファイル（`platform_overrides.txt`）に保存し、次回起動時に反映
- **データ駆動のステージ構築**（`LevelManager`）
  - 足場・チェックポイント・ガイドテキスト・リスポーン地点をデータとして定義し、共通のビルダーで生成
- **チェックポイント／リスポーンシステム**
- **分岐を含む全 15 ステージ**

### 🛠️ 開発環境

- **言語**：C++
- **グラフィックス API**：DirectX 11（HLSL シェーダー、DirectXTex）
- **開発ツール**：Visual Studio 2022

## 中文

### 📖 專案簡介

讀取手繪文字或插圖的圖片，把畫出來的部分直接轉換成有碰撞判定的平台的 2D 平台跳躍遊戲。
不使用遊戲引擎，以 C++ 與 DirectX 11 自行實作繪製、輸入、碰撞判定與關卡管理。

### ✨ 主要功能

- **圖片 → 平台自動轉換**（`ImageToPlatform.h`）
  - 將圖片切成固定大小的網格，依 Alpha 值與亮度判定「墨水」像素
  - 墨水比例超過閾值的格子產生為矩形平台（AABB）
  - 邏輯與 DirectX 分離，並以單元測試（`test_image_to_platform.cpp`）驗證
- **遊戲內關卡編輯器**（`PlatformEditor`）
  - 在除錯飛行模式下，用滑鼠選取、移動、縮放平台、圖片群組與檢查點
  - 圖片平台以「外觀 Sprite＋產生的碰撞方塊群」為一組整體操作
  - 按 `S` 將編輯結果存到文字檔（`platform_overrides.txt`），下次啟動時套用
- **資料驅動的關卡建構**（`LevelManager`）
  - 平台、檢查點、引導文字、重生點以資料定義，由共用的建構函式產生
- **檢查點／重生系統**
- **含分支路線的 15 個關卡**

### 🛠️ 開發環境

- **語言**：C++
- **圖形 API**：DirectX 11（HLSL 著色器、DirectXTex）
- **開發工具**：Visual Studio 2022
